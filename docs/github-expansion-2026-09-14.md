个人库保存固定提交、完整入口和所需参考图；没有执行上游代码。本轮使用作者原样例看方向，没有逐一重新生成验证图。图鉴选用咖啡露台、海边、树街、森林、人物特写与抽象样张。

## 后续维护

本轮按用户明确请求收录，没有后台自动升级。图鉴的「复制使用指令」通过 Photo Alchemy 读取已安装包。Albert 精确尺寸导出需要其声明的 Node 22+ 和 ImageMagick 7；生图使用当前环境的内置工具。本轮没有为收藏安装额外依赖或启动上游服务。

这些是人工审阅后的完整包，超出简易网页安装器的纯文档范围。更新时先核对原来源，再交给 Codex 更新完整包。Albert 的六个目录条目必须一起更新 commit，并保留 sourceStyle 与 styleEntry，不能只改其中一个。安装器拒绝复杂依赖不等于源包不可用，复制文件也不代表完成效果测试。
