# 跨题材试作记录 · 2026-09-14

目的：验证相同方法能否依据不同输入提取结构，不以生成好看的目的地场景代替迁移。

本轮是受控试作：两种方法各处理食物、植物、建筑三类输入。输入为本项目合成的照片，食物与植物为本轮新增，建筑复用此前合成庭院；不是用户私照，也不代表自然照片分布。每张输出均通过内置 ImageGen 引用对应原始输入；未以另一张生成结果充当原始照片。没有工具返回的型号证据，不标注 Image 2.5 已验证。

| 方法 / 输入 | 主要检查 | 观察与限制 |
|---|---|---|
| 五形 / 食物 | 一梨、一碟、两杏仁；左右位置；形状归并 | 数量与关系可读；梨面仍有体积渐层，平面化不完全 |
| 五形 / 植物 | 两叶、一枝、对应投影；完整叶形 | 首版裁断上叶并保留整枝摄影纹理；一次修正后两项解决，仍有轻微色面渐变 |
| 五形 / 建筑 | 三处不等开口；斜向水池；深蓝/米白/青绿关系 | 主形咬合可辨；橙色植被合并，不保证所有细小物件逐一保留 |
| 光影 / 食物 | 源物与投影方向；一梨、一碟、两杏仁 | 首版仅局部涂平；一次修正放大投影、缩小证据后与五形拉开差异；不是精确物理投影 |
| 光影 / 植物 | 两叶及对应影形；次序；源色关系 | 首版仍是写实墙面；一次修正改成大影形和小叶片证据，仍有微弱渐层；艺术重组不锁定像素坐标 |
| 光影 / 建筑 | 水面反射分支；三处开口与倒影的对应节奏 | 放大倒影并简化背景，局部保留水纹证据；倒影形状是艺术性翻译，不能作物理复原 |

缩略观看：五形的主体形状更先被读到，光影的影形/反射节奏更先被读到。两者具有可见差别；“更好看”仍是审美选择，未进行用户盲评，未给出虚构评分。

## 固定规则与输入映射

完整可复用规则在 `styles/city-five-shapes.md` 与 `styles/courtyard-shadow-atlas.md`，公共提炼流程在 `docs/style-grammar.md`。输入—输出对应文件见 `transfer-examples.json`，源图与选定输出保存在 `assets/transfer/`，建筑源图为 `assets/examples/source-courtyard.png`。所有输出均使用内置工具，无代码绘制替代。

每次编辑提示均遵循：实际输入为编辑目标；记录数量、相对关系与独特线索；应用所选方法；源图归并配色；依据横竖幅、密度与真实光学关系改变构图；不添加样张对象、地点、文字或隐藏视角。

- 五形：把源图归并为约 4–6 个主形，主体保持完整，以负形/共边连接；删除连续摄影纹理与体积渐层，细节只留识别点。
- 光影：从真实投影/透光/反射选一条主关系，扩大连贯光影面，缩小少量来源证据；保留对应次序与方向，可艺术性改变尺度；拒绝整面摄影背景。
- 食物映射：梨/碟与两颗杏仁作为数量线索；投影方向来自输入。
- 植物映射：两片银杏叶在一根树枝上的连接及投影次序；上叶黄边作为识别点。
- 建筑映射：三处开口与斜向水池；光影方法选择可观察的水面反射，不把深色墙漆假定为阴影。

失败规则已回写两个方法：完整轮廓不得误裁，整根树枝摄影纹理不等于提炼；光影须建立独立观看重心。其他九种原创方法本轮完成规则与适配条件重写，仍沿用已有方向样张，尚未完成相同规模的迁移试作。社区原图仅作其原方法的参考，本轮未逐一重新生成或宣称全面提升。
