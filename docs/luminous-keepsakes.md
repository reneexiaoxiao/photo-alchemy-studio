# 通透釉面与五种冰箱贴

2026-09-21，新增6个 Renee 原创工作流。现有马赛克、贝壳矿物像素和浅浮雕冰箱贴连同原示例继续保留；图库共59种。这里的原创指具体照片转译规则与新增文字，不主张发明瓷砖、珐琅、树脂、流沙或贝壳工艺。

## 选哪个入口

| 想要的效果 | 入口 | 换照片仍保留的规则 |
|---|---|---|
| 更润泽、通透的小瓷砖 | [通透釉面马赛克](../styles/glazed-ceramic-mosaic.md) | 规整砖块与少量切角、细凹缝、积釉、微圆边和局部高光 |
| 金线边的彩色金属小物 | [金线珐琅冰箱贴](../styles/gold-enamel-magnet.md) | 细金线沿真实结构分区，源色化为珐琅色面 |
| 中间能透出底色 | [透光树脂冰箱贴](../styles/translucent-resin-magnet.md) | 清透区、薄厚积色与厚边折射，不能整片堵上不透明背板 |
| 流沙在夹层里沉积 | [流沙夹层冰箱贴](../styles/liquid-sand-magnet.md) | 固定主体、连续封边浅腔、底部少量细沙，主角不被淹没 |
| 安静而有珠光的贝片 | [珠母贝镶嵌冰箱贴](../styles/nacre-inlay-magnet.md) | 随形大贝片、方向性层理和有限虹彩，不是规则方格像素 |
| 真空洞与影子相呼应 | [镂空浮影冰箱贴](../styles/openwork-shadow-magnet.md) | 来源骨架、真实镂空、合理连接与对应短投影 |

所有入口从当前照片重新提取主体、数量、关系、源色和空隙；不会固定生成样例的蓝门、拱廊、银杏、梨或某个目的地。默认不添加地名、日期、标语或新景点。冰箱贴的连接、背托和封边是作品结构，不能拿它们当理由改写照片内容。

五个磁贴入口与原冰箱贴属于同一推荐家族。普通随机选风格时优先给不同视觉方法，避免一组结果都变成磁贴；明确比较冰箱贴方向时，可以逐个从原照生成。新增瓷砖与既有沿形马赛克也共享推荐家族。

## 本轮实际示例

本轮每个新入口各有一个真实输入转译样例，总共使用6张不同输入。银杏、梨与碟子、蓝门海岸、拱廊均为本项目已有合成测试照片；海边与街树为 Albert 公开示例照片。样例不代表已经对各种用户照片做过广泛验证。

| 方向 | 来源联系与观察 |
|---|---|
| 通透釉面 | 蓝门、三只花盆与海岸位置保留；釉面、砖块与细缝明显，门环和台阶仍带浅浮雕倾向，不能称为完全平面化。 |
| 金线珐琅 | 三道拱、三只橙子与斜向水池保留；修正后池面归并为色块，金线成为结构分区。 |
| 透光树脂 | 两片银杏与斜枝关系保留，薄边和叶片较清透，厚处积色与淡色影可辨。 |
| 流沙夹层 | 海边三人的姿态关系、伞与低日保留，封边与底部沉沙可辨；只验证静态视觉效果。 |
| 珠母贝 | 一梨、一碟、两颗杏仁保留，较大贝片与局部层理可辨；连接背托借用源图影形，染色贝片为表现选择。 |
| 镂空浮影 | 树干在右、枝势向左、街道负形保留；细小人物和招牌被省略，以树与屋檐为主要锚点。 |

样例由内置 ImageGen 生成，工具没有提供可核验的具体模型型号。图像展示的是纪念物设计概念，不是能直接生产的 CAD、磁力测试或流体模拟；流沙不会因这张静态示例在网页中自动运动。轮廓和可见连接并不证明实物强度。

通透瓷砖的陶胎仍是不透明的，通透感来自釉层深浅与光泽；树脂可以透出底色；镂空则是真正留空。生成时应分别表达这三种视觉机制。

尺寸、修正次数与逐图限制见 [样例记录](keepsake-sample-review.json)。
