## 名称与入口

| 用户提供的方向 | 图鉴入口 | 处理方式 |
|---|---|---|
| 齐白石方向写意水墨双联 | `xieyi-ink-diptych` 写意墨趣双联 | 新增；3:4、上下各半、下半主体18%–35%、全图无字 |
| 立体折纸与纸雕拼贴双联 | `folded-paper-diptych` 折纸造物双联 | 新增；3:4、各半、真实折面与纸字标题 |
| 主题光影海报 | `luminous-silhouette` 光窗剪影 | 新增；单幅柔光容器、主次剪影，可从照片或主题进入 |
| 贝壳矿物像素双联 | `shell-mineral-diptych` 贝壳矿物像素双联 | 新增；4:5、各半、天然方格小画与极小英文短句 |

| 旅行记忆拼贴海报 | `souvenir-constellation` 碎片星图 | 已有方法新增旅行拼贴分支；支持别名搜索 |
| 喜茶风格实物海报 | `editorial-object` 留白实物海报 | 按描述独立实现；保留搜索别名，无品牌官方关联 |
| 剪纸拼贴风海报 | `paper-scene-memory` 剪纸叙事 | 复用已有平面剪纸方法；支持别名搜索 |
| 手绘感扁平插画 | `handdrawn-flat` 手绘平涂 | 按描述独立实现；不是博主的 LOVART 工程或原 Skill |

“新几何扁平”与“五形提炼”区分在标准模块和重复秩序；折纸以折面产生体量，剪纸以薄片关系产生叙事，纸雕层景以真实前后开窗产生深度；“光窗剪影”可以构造表现性的光区，“光影提炼”主要从源图已有光学关系出发。

## 来源与署名

前四项参考用户给出的完整文字方向，后三项新工作流参考用户转述的视频风格名称。本项目没有获得可核对的原作者名称、视频链接或原 Skill 版本，不将其标成上游安装，也不冒充博主的同款成品。用户消息中的原提示词不作为公开文件再分发。

新增文件是 **Renee 整理、独立实现，AI 辅助**；图鉴标记为“Renee 参考实现”。这里的署名指本项目新增规则、路由与文字，不主张水墨、折纸、贝壳镶嵌或相关艺术方向为 Renee 首创。MIT 只覆盖本项目可以授权的新增实现；不改变原提示词、品牌、第三方作品的权利状态。

没有上传视频或具体参考图的三个方向，是基于描述的可用实现，不宣称精确复刻。以后获得准确原 Skill，可另行核验与记录，不覆盖本次的独立实现来源。

## 本轮示例与实际限制

每个新方向有一张输入转译样例，使用植物、器物、建筑、海边人物和街景5种输入。样例用于看效果，不构成同一方法对所有题材稳定的证明。未用本次示例替换社区原参考图。

| 风格 | 输入与检查重点 |
|---|---|
| 写意墨趣双联 | 合成银杏照片；两片叶、枝势、无字与留白。上半改为竖照容纳在横向区域，图像工具仍可能重绘细节，不能称原像素锁定。 |
| 折纸造物双联 | 合成梨与碟子；一梨一碟两颗杏仁、折面与纸纤维；`STILL` 是本次艺术标题。 |
| 光窗剪影 | 合成拱廊；三处拱形节奏与橙枝位置，光窗是艺术构造，非拍摄现场事实。 |
| 贝壳矿物像素双联 | Albert 海边照片；三人姿态、伞与海平面、材料方格；当前分区约48%/52%，一次修正后仍未达到严格等分；`Stay a little longer.` 是本次艺术短句。 |
| 新几何扁平 | 合成拱廊；重复圆弧、泳池梯形与橙色锚点，局部仍可能有柔微色差。 |
| 留白实物海报 | 合成梨与碟子；真实物性、双物关系与留白，不是喜茶品牌官方样例。 |
| 手绘平涂 | Albert 街树照片；树枝弧势、街道负形与源色关系，低优先级人群与招牌细节被简化。 |

三个双联模块都把精确比例写入调用规则；整图生成不能代替像素级原照锁定或精确印刷装版验收。对实际用户照片执行时仍需核对中线、比例与人物/物体漂移。若一次定向修正后仍偏离，就记录实际限制，不能把接近值标为严格达成。

图像使用内置 ImageGen 生成，未获得可核验的具体模型型号，不声明某个型号已完成验收。每个失败样例最多一次针对性修正。本轮实际尺寸与分界记录见 [样图检查](september-sample-review.json)。
