# 摄影与再创作双联规则

适用于 `xieyi-ink-diptych`、`folded-paper-diptych`、`shell-mineral-diptych`。它们是每张照片各出一张成品；多张上传按顺序分别处理，不能拼成一个合集。共同规则只在选中这些模块时生效。

## 画幅与上半区

- 水墨与折纸为竖版 3:4；贝壳矿物为竖版 4:5。画布高度必须可二等分，分界在准确的 H/2，上下各占 50%，没有第三个标题区或中间间隔。参考输出尺寸分别为 1200×1600 与 1200×1500。
- 把实际照片作为编辑目标传入。上半区保留主体数量、朝向、相对位置、透视、真实材质与自然光色，不将主体拉宽或压扁。
- 水墨要求完整原照：等比容纳整张图，长宽比不同时以安静纸色补足上半区空处，不裁掉源图。折纸和矿物允许轻微调色与非主体环境延展；只有天空、墙面、地面等连续背景可以延展，不能复制人、建筑开口或物体来填画幅。延展会编造主体结构时，改为等比容纳并留边。
- 原照片本来已有裁切的对象，不推测补齐不可见部分。下半区的“完整”指将可观察的核心组合完整收在画面内。
- 水墨整图无字；输入中已有字样时，不得凭空改成伪字。可在用户明确允许的无字化范围内去除；若同时要求原像素绝对不变，两者冲突需说明并由用户选择。

## 下半区与文字

下半区的主体尺度、材料和文字策略按所选模块执行，不把一个模块的标题习惯带到另一个模块。空白面积按下半区单独计算。源图的对象、地点、颜色与示例无关；必须重新从当前输入提取。

水墨禁止全部文字，包括印章字符与伪书法。折纸允许一个由图像概括的英文词，明确它是艺术标题，不是地点或事实标签。矿物允许一句很短的英文感受句：用户提供时逐字使用；没有提供时可从观察到的关系拟一句，并在交付文字中说明所用短句。日期、编号、地点与品牌只在用户提供且要求使用时出现。标点不能伪装署名或水印。

## 生成与核对

默认用内置 ImageGen 生成整张作品。提示词写明准确纵横比、H/2 分界、上半摄影的保护范围以及下半的独立规则。优先用图像编辑保护上半区；整图生成仍可能重绘摄影区域，不能称为原像素锁定。

逐项对照原图：上半身份、数量、角度、边界；下半可辨锚点、主体大小和留白；分界是否在正中；所有文字是否符合该模块。尺寸检查与目视内容检查分别记录。一次针对性重试仍不符合时，说明未达成的条件，不能把“约各半”写作严格验证通过。需要像素级锁定或精确印刷装版时，先确认可用的保真拼版方式；未经实际执行不能承诺像素不变。
