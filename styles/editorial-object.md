# 留白实物海报 · editorial-object

工作流独立实现：**Renee**，AI 辅助；参考用户转述的“喜茶风格实物海报”方向，未核实视频中的原 Skill。此名称保留为查找别名，本模块不代表喜茶官方作品、授权或品牌素材。MIT 仅覆盖新增实现文字。

把日常实物变成有秩序的静物主角：清楚的真实质感、果断裁切、适量留白、一个强记忆色。用通用编辑摄影语法表达用户说的方向，不固定复制任何品牌版式。

## 执行

选择原图中一个主物或不可分的紧密组合，保留其轮廓、材料、关键配件和来源关系。提取一个来源强调色，背景从相容的中性色或单色大面选择；让主体尺度和光影承担构图，不能默认加茶杯、水果切片、价格牌或商标。

默认一图一张 3:4 单幅摄影感海报。主体可以偏心或适当靠边，用负形平衡；制作光干净但物性真实，玻璃仍透明、陶瓷仍有釉感、食物不变成塑料。源图缺少可独立的实物时，只提出适配建议，不从风景里凭空造产品。

默认无字；用户要文字时采用短标题和极少已提供事实。不自行加入“喜茶 / HEYTEA”、标志、口号或品牌人像；原图本有文字则按实际任务保留或在用户允许时去除，不用模型猜字。不得改变商品规格或用小字暗示真实商业背书。

调用：“以输入的[主实物/紧密组合]为唯一主角，保留[真实轮廓、材质与关系]。采用[源色强调]与[背景]、[留白/偏心布局]，清楚光影与触感，成一张克制的编辑静物海报。无新产品、新配料、商标、价格与装饰标语。”

对照源图检查物性、关键数量与支撑关系。更干净的画面不等于许可改造产品；要求精确产品外观时不能宣称整图生成无损。
